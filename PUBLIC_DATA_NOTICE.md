# Замечание

В публичном репозитории содержатся только программный код и сводные результаты экспериментов.
В него не включены: исходный корпус документов, экспортированные данные из Telegram, локальный векторный индекс, полный набор проверенных эталонных тестов, сгенерированные ответы/контексты, сформированные пары для обучения или контрольные точки (чекпоинты) моделей.
